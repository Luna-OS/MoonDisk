# Placeholder icons

The PNG/ICO files in this directory are **temporary placeholders**: flat
MoonDisk night-blue squares with no design work, generated only so
`tauri.conf.json`'s `bundle.icon` list points at real files and the
Phase 2 scaffold build/bundle succeeds.

They will be replaced wholesale in **Phase 3 – Branding, Icon und
Axolotl-Maskottchen** (see `docs/roadmap.md`), once the real MoonDisk icon
is derived from `assets/branding/moondisk-icon.svg` (see `docs/branding.md`
and `docs/icon-conversion.md`).
